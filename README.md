# 🧠 Advanced Text Summarization and Paraphrasing App

This project is an AI-based web application that performs **Text Summarization** and **Paraphrasing** using advanced Natural Language Processing (NLP) techniques.  
It was developed as part of the **Infosys Springboard Virtual Internship** program.

---

## 🚀 Features
- 📝 Summarizes long paragraphs into concise text  
- 🔁 Paraphrases content while maintaining meaning  
- 🎤 Accepts both **text** and **speech input** (if added)  
- 💾 Download summarized text  
- 🌐 Simple and interactive Streamlit web interface  

---

## 🧩 Technologies Used
- **Python**  
- **Streamlit** – for frontend UI  
- **Transformers (Hugging Face)** – for NLP models  
- **Torch (PyTorch)** – for model backend  
- **TextBlob / NLTK** – for text processing
