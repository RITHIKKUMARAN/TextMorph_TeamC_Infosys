# 🧠 Text Summarization and Paraphrasing App

This project is an **AI-based web application** that performs **text summarization** and **paraphrasing** using advanced Natural Language Processing (NLP) models.  
It was developed as part of the **Infosys Springboard Virtual Internship Program**.

---

## 🚀 Features
- Summarizes long text into concise and meaningful content  
- Paraphrases text while retaining the original context  
- Fast and accurate NLP processing using Transformer models  
- Simple and interactive Streamlit web interface  

---

## 🛠️ Tech Stack
- **Python**
- **Streamlit**
- **Hugging Face Transformers**
- **PyTorch**
- **NLTK / TextBlob**

 ## 4. 🧠 How It Works

User enters or uploads text into the app.

The model processes the input using Transformer-based NLP algorithms.

Generates either a summarized or paraphrased version of the text.

Output is displayed on the Streamlit interface for the user.

## 5. 🎯 Objective

To build a smart and efficient AI-powered tool that can summarize and paraphrase large texts quickly — saving time and improving readability.
