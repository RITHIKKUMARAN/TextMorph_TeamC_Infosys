## 🚀 Features
- 📝 Summarizes long paragraphs into concise text  
- 🔁 Paraphrases text while keeping original meaning  
- 🎤 Supports **speech-to-text input** (optional)  
- 💾 Allows **downloading** the summarized content  
- 🌐 Clean, fast, and interactive **Streamlit interface**

## 🧠 Working of the App
1. The user inputs **text or speech** into the web app.  
2. The **NLP model** processes the content using **Transformer models**.  
3. Generates either a **summary** or a **paraphrased version**.  
4. The result is displayed on the **Streamlit interface** instantly.  
5. The user can **copy or download** the output easily.
